# Проект "Конструктор"

## Технический стек
**Frontend**: <br>
HTML, CSS, JavaScript (с шаблонизатором EJS)

**Backend**: <br>
Node.js, Express.js

## Описание
Проект “Конструктор” – это fullstack web-приложение для ведения блога, 
предоставляющее инструменты как для написания статей через графический 
интерфейс, так и для чтения статей других пользователей и взаимодействия 
с ними.

## Технические возможности
- вход и регистрация
- личный кабинет (аккаунт)
- создание, редактирование, удаление, скрытие статей от других
- закрепление особо важных статей на самом верху ленты
- чтение статей других пользователей
- реакции в виде кнопок “Понравилось” и “Не понравилось”
- уникальные ссылки на статьи, которыми можно делиться
- адаптируемость под экраны как компьютеров, так и мобильных устройств
