## Обзор
Конструктор – это фуллстек веб-приложение для ведения блога, предоставляющее инструменты как для написания статей через графический интерфейс, так и для чтения статей других пользователей и взаимодействия с ними. 

Вместо традиционной базы данных приложение использует локальное JSON-хранилище, которое автоматически синхронизируется с удаленным репозиторием GitHub: перед отправкой данные надежно шифруются, а перед чтением - расшифровываются. JSON-база предоставляет неплохие возможности для хранения и позволяет избежать необходимости в развертывании и поддержки сложных БД.

Рендеринг страниц (главная, авторизация, профиль, просмотр статей) происходит на сервере через шаблонизатор EJS - благодаря чему первый экран загружается почти мгновенно. При этом вся динамическая логика построена на собственном RESTful API: интерфейс может асинхронно выполнять действия без перезагрузки страницы: вход / регистрация, подгрузка статей, кнопки “Понравилось” и “Не понравилось”.

Основные возможности:
- вход и регистрация
- личный кабинет (аккаунт)
- создание, редактирование, удаление, скрытие статей от других
- закрепление особо важных статей на самом верху ленты
- чтение статей других пользователей
- реакции в виде кнопок “Понравилось” и “Не понравилось” с защитой от накрутки
- уникальные ссылки на статьи, которыми можно делиться
- адаптируемость под экраны как компьютеров, так и мобильных устройств

Технические характеристики приложения:
- Поддержка RESTful API
- Умная выборка данных на эндпойнте: фильтрация скрытого контента, пагинация, хронологическая сортировка

```
├── views/          // Отображаемые страницы и компоненты

  └── img/          // PNG, SVG - Файлы логотипов в разных формах и цветах
├── index.js        // JS - Файл сервера
└── README.md
```

## Будущие возможности
В настоящее время Конструктор переезжает на новый, более современный стек и в [новый репозиторий](https://github.com/ProofMrNick/Constructor_FullStack_MERN_Project). 
Ключевые изменения:
| Уровень | Было | Будет |
|---|---|---|
| Frontend | HTML, CSS, JavaScript (с шаблонизатором EJS) | React.js |
| Движок| Статические страницы | Vite |
| Backend | Node.js, Express.js | *без изменений* |
| Хранилище данных | Зашифрованный JSON-файл | Mongo DB (Mongoose) |
| Хостинг | ONREZA | Railway |

Хотя существующее веб-приложение показало хорошие результаты работы и отличное выполнение поставленных задач, код-база все же требует значительного рефакторинга и смены технологического стека для улучшения не только масштабируемости, но и непосредственной читаемости кода, а также для соответствия современным паттернам программирования на JavaScript. Помимо этого, в настоящий момент идет переработка дизайна страниц в более удобный для работы вид.
